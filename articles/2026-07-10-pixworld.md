# PixWorld：在像素空间统一 3D 场景生成与重建

原文链接：https://sensengao.github.io/PixWorld/
论文：https://arxiv.org/abs/2607.05373

---

## 原文整理

### 核心思路

PixWorld 的出发点是：3D 场景「生成」和「重建」本质上是同一件事——都是从已知视角推断未知视角。过去的方法把它们分开处理，或者统一但要过一个 VAE/latent autoencoder 中间层，信息在这里就已经有损耗了。

PixWorld 直接在像素空间操作，把多视角输入分成两个子集：
- **clean 子集**（重建）：有 ground truth 的帧，直接用
- **noisy 子集**（生成）：加噪的帧，diffusion 去噪生成

两个流共享同一个 two-stream MMDiT transformer，joint attention 让它们在每一层互相看到对方，最后解码出像素对齐的 3D Gaussian 表示。

### 关键创新：Geometry Perception Loss

2D photometric loss（PSNR/LPIPS）只能保证单帧看起来合理，但不约束跨视角几何一致性。PixWorld 引入了一个额外的 geometry perception loss：在预训练 3D foundation model（π³）的 feature space 里对齐 rendered 视角和 ground truth 视角。

消融实验结果很清楚：去掉这个 loss：
- PSNR 下降 1.13 dB（19.12→17.99）
- AUC@5 下降 12.5%（0.642→0.562）
- VBench 感知指标几乎不变

说明 2D 视觉指标感知不到的 3D 结构问题，这个 loss 能捕捉到。

### 性能数据

- **速度**：~0.6s/场景（480P，4-step distilled），比扩散生成方法快 ~1000x
- **WorldScore**：71.04 平均分，Camera Control 91.08（第一），3D Consistency 91.39（第一），Photometric Consistency 93.84（第一）
- **重建**：RealEstate10K 4-view，PSNR 26.21 dB，LPIPS 0.138，超过 LVSM 和 DepthSplat
- **模型规模**：1.04B 参数，从头训练，32 × A800-80G，200K steps

### 架构细节

Two-stream MMDiT：
- Clean stream 和 Noise stream 各自维护独立的权重（QKV、MLP、adaLN-Zero）
- 但 attention 是 joint 的——两个 stream 的 Q/K/V 在 token 维度拼接后做一次完整的 attention，再分开走各自的 output projection
- 这样 clean frame 的几何信息可以"流"到 noisy frame 的去噪过程中
- 相机参数用 PRoPE（Cameras as Relative Positional Encoding）注入

训练数据：Re10K + DL3DV-10K（~67K 场景）+ 10M BLIP-3o 单图（作为 2D appearance prior 共享 diffusion backbone）

## 启发与见解

**"损耗在中间层"** 是一个很通用的架构教训。VAE/latent 中间层压缩了信息，而这些被压缩掉的信息可能正是你真正需要的（比如精确的几何结构）。PixWorld 的选择是直接在像素空间操作，绕过这一层。

这跟我们在做 Liquid Glass 逆向时发现的事情有共鸣——CASDFLayer 的渲染管线也是绕过了 UIKit 的普通 blur layer，直接在 QuartzCore 层做 SDF shader，正是因为中间层会损失精度。"下沉一层"是一种解决精度问题的通用思路。

**Geometry Perception Loss 的设计思路**值得记：当你的训练目标无法直接度量你真正关心的属性时，找一个预训练好的"感知器"（这里是 π³ 3D foundation model）来补这个 gap。这跟 LPIPS 用 VGG 感知特征替代像素 MSE 是同构的，只是维度从 2D 扩展到 3D。以后在 neuro-substrate 里设计 cortex schema loss 时可以借鉴这个思路——不只是 reconstruction loss，还需要一个"结构感知器"。

**两流共享 joint attention** 的设计很优雅：让已知视角的几何信息自然"渗透"到待生成视角的去噪过程，而不是通过额外的 cross-attention 显式传递。条件信息的注入方式决定了耦合的紧密程度。
